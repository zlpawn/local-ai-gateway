Codex 代理

为兼容 OpenAI 接口的独立 Codex 客户端提供下游代理支持。

🚀 如何连接此网关？

对于独立的 Codex 桌面端或命令行：保存本页配置后，网关会自动生成模型目录文件 ~/.codex/gateway-model-catalog.json（官方模型 + 下方 Codex 节点里的第三方模型）。把下面片段贴到 ~/.codex/config.toml，并确保放在第一个 [section] 之前：

model_provider = "custom"
model_catalog_json = "~/.codex/gateway-model-catalog.json"
openai_base_url = "http://127.0.0.1:8787/codex/v1"

[model_providers.custom]
name = "Shrimp"
base_url = "http://127.0.0.1:8787/codex/v1"
wire_api = "responses"
requires_openai_auth = true
experimental_bearer_token = "dummy"

说明：改 Codex 节点/模型后点保存即可刷新目录文件，不必手动跑 npm run codex:catalog。若 Desktop 已打开，保存后重启或重载 Codex 才能看到新模型。

切换到 model_provider = "custom" 后，旧会话可能暂时不显示。可点右上角「迁移历史会话」：先预览数量，确认后再写入；会自动备份 ~/.codex，不影响登录态和插件。

DeepTutor 代理

为 DeepTutor 客户端提供 OpenAI 兼容的下游代理支持。默认从 Codex 复制节点与密钥。

🚀 如何连接此网关？

DeepTutor 走 OpenAI 兼容协议。大语言模型 base_url 填 API 根路径；向量模型 base_url 填完整 embeddings 端点（DeepTutor 会直接 POST 到该地址）：

大语言模型 base_url：http://127.0.0.1:8787/deeptutor/
向量模型 base_url：http://127.0.0.1:8787/deeptutor/emb/embeddings

首次进入时若 DeepTutor 为空，网关会自动从 Codex 复制节点与密钥。

💡 使用说明

网关扫描 PATH（及 Windows 常见安装目录）中的可执行文件。默认只显示「推荐」CLI（系统规则自动挑出的常用工具）。Git/MinGW 等工具链内部二进制会被硬过滤。若某个工具不在推荐里，请切到「全部」点「设为常用」固定进来；推荐列表里只对你手动固定的项显示「取消常用」。

扫描来源

管理 CLI 扫描的安装来源及其目录。默认包含 uv、npm、curl、homebrew、winget、irm、PATH，可新增自定义来源（如 chocolatey）。

💡 使用说明

每个来源包含名称、标签、是否启用、以及一个或多个扫描目录。目录支持 ~、环境变量（HOME / %APPDATA%）和通配符 *（如 ~/.nvm/versions/node/*/bin）。特殊值 PATH 表示扫描系统 PATH 目录。

来源按列表顺序优先扫描，先扫到的二进制优先归属该来源。例如 uv 来源排在 npm 之前，一个同时被两者安装的 CLI 会标记为 uv。
