# 易经六十四卦工具设计

## 概述

在网关桌面面板的"迷你工具"模块中新增一个易经六十四卦工具。用户可通过可转动的双圆环浏览六十四卦，点入查看每卦的完整卦辞、大象传、六爻爻辞及小象传。纯前端实现，离线可用，不依赖后端 API。

## 架构

沿用现有迷你工具模式（与 classification-metrics、video-kb 等一致）。新增三个产物：

- `desktop/src/modules/iching-data.ts`：六十四卦结构化数据，由抓取脚本从 ctext.org 生成
- `desktop/src/modules/iching.ts`：圆环渲染、拖拽交互、详情页渲染逻辑
- `panel.css` 追加 "I Ching Module" 段落

在 `app.ts` 中注册：
- `toolGroupConfigs` 新增「国学」分组，含 `iching` 工具
- `toolDefs()` 注册 `iching` 的名称、描述、图标
- `openTool()` 路由加 `iching` 分支，调用 `renderIchingDetail()`
- 顶部 import `renderIchingDetail`

## 数据来源

### 来源
ctext.org（中国哲学书电子化计划）每个卦有独立页面，URL 格式 `ctext.org/book-of-changes/{卦名拼音}/zhs`。每个页面的经传文本用 `<td class="ctext">` 结构化存储，按固定顺序排列：

- 索引 0：卦辞
- 索引 1：彖传（本工具暂不收录）
- 索引 2：大象传
- 之后成对出现：爻辞 -> 小象传，循环六次
- 乾卦额外有「用九」爻辞和小象传，坤卦有「用六」

已抓取并验证乾卦页面，结构清晰可解析。64 卦的拼音路径已全部拿到。

### 数据结构

```typescript
interface IchingLine {
  position: string;   // "初九" | "九二" | ... | "上九" | "用九" | "用六"
  text: string;       // 爻辞原文
  commentary: string; // 小象传
}

interface IchingHexagram {
  number: number;           // 1-64 卦序
  name: string;             // "乾" | "坤" | ... | "未济"
  symbol: string;           // Unicode 卦符 ䷀-䷿
  pinyin: string;           // ctext 路径名 "qian" | "kun" | ...
  upperTrigram: string;     // 上卦 "乾" | "兑" | "离" | "震" | "巽" | "坎" | "艮" | "坤"
  lowerTrigram: string;     // 下卦
  judgment: string;         // 卦辞
  image: string;            // 大象传
  lines: IchingLine[];      // 六爻（乾卦含用九，坤卦含用六）
}
```

### 生成流程

写一次性抓取脚本（不进项目），从 ctext.org 抓取全部 64 卦页面，解析 `<td class="ctext">` 成上述结构，生成 `iching-data.ts`。生成后抽查乾、坤、泰、既济、未济与 ctext 原文对照确认无误。

## 圆环交互

### 布局

两个同心 SVG 圆环：

- 外环：64 格，每格放该位置卦的上卦三爻符号
- 内环：64 格，每格放该位置卦的下卦三爻符号
- 卦名小字沿圆环外侧弧形排列
- 顶部固定指针标记当前对齐位置
- 圆环中心放一个极简太极图（两段弧线，不填色，`--text-secondary` 细线勾勒）

标准对齐状态（rotation=0）下，圆环按六十四卦卦序排列，某一角度位置上下卦组合出该卦。

### 交互

- 两环各自独立拖拽旋转，pointer 事件驱动旋转角度
- 拖拽时实时计算顶部指针所指格子，组合出当前卦，在指针下方显示卦名
- 松手后带物理惯量减速，像重物在转盘上自然滑停（参考王也风后奇门盘的转动重量感）
- 点击当前卦进入详情页
- 「复位」按钮把两环动画转回标准对齐（rotation=0）

### 复位语义

每个卦的上下卦在标准卦序中是固定的。转动环会错位，组合出非该位置标准的卦。复位把两环转回 rotation=0，恢复标准卦序，每个角度回到它原本固定的上下卦。

## 视觉

参考《一人之下》王也风后奇门盘的气质：盘面沉、爻线亮、转动有分量。克制的暗金点缀，不堆砌中国风元素。

### 字体分层

- 卦名和经传原文用中文衬线字体（Songti SC / STSong 系统宋体），传达典籍感
- UI 控件（按钮、提示）用面板现有无衬线，保持工具属性
- 两层字体各司其职

### 色彩

整体维持面板灰阶，唯一引入一个克制的暗金色作为强调色：
- 暗色主题：约 `#b8956a` 量级
- 亮色主题：深一档
- 只用在三处：当前指针所指卦格的高亮边框、当前卦名颜色、进入详情的点击提示

### 爻线发光

- 爻线用 `--text-primary` 描边，再叠一层极轻同色 blur（暗色主题约 `rgba(250,250,250,0.15)` 微辉）
- 像"暗室里一根烛火"的克制亮，不是霓虹
- 当前指针所指卦格的爻线辉光略强，明暗交替形成视觉焦点

### 盘面凹陷感

- 圆环区域用径向渐变从中心向外微微变深
- 配合一道极细 inset 边线，营造"刻进地面"的凹陷感
- 像王也脚下那个盘从地里浮出来的质感

### 中心太极

- 圆环正中心放极简太极图，两段弧线不填色，`--text-secondary` 细线勾勒
- 小而安静，不抢圆环的戏

### 动效

- 拖拽时圆环平滑跟手
- 松手后物理惯量减速自然滑停，转盘有"分量"
- 复位时缓动回正
- 当前卦格暗金高亮有微妙呼吸感
- CSS `transform: rotate()` 驱动
- `prefers-reduced-motion` 时退化为瞬时切换，不动画

## 详情页

点卦进入详情，垂直排列显示：

- 返回按钮（复用 `tools-detail-back` 样式）
- 卦符、卦名、卦序
- 上下卦组成（如「乾上乾下」）
- 卦辞
- 大象传
- 六爻：每爻含位置名、爻辞原文、小象传，逐爻展开
- 用九/用六（若有）单独列出

经传原文用衬线字体展示，行距放宽，留白充足，像翻开一本古籍。爻辞逐条展开，每条用极细分隔线隔开，不用卡片框。

## 取舍

- 不引外部库，纯 SVG + pointer 事件
- 数据文件随项目分发，离线可用
- 彖传、文言传暂不收录，后续需要再加
- 起卦/占卜功能留到后期

## 验证

- 抽查数据：乾、坤、泰、既济、未济与 ctext.org 原文对照
- 圆环渲染：在面板中实际打开工具，确认 64 格显示正确、拖拽旋转流畅、复位准确、爻线发光与暗金高亮视觉到位
- 详情页：点入几个卦确认完整显示卦辞、大象传、六爻爻辞及小象传
- 暗色/亮色主题切换确认对比度达标
