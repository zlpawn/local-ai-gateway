# 职场嘴替表情包助手

这个 skill 用来根据用户输入的表达意图、情绪或聊天场景，搜索并下载合适的中文表情包。优先理解用户真正想表达的语气，再提取关键词调用脚本。

不要抓网页，不要临时分析页面。直接使用 `scripts/bqb_search_download.py` 搜索和下载。

## 使用流程

1. 判断用户想表达的情绪、态度或聊天场景。
2. 提取 1-3 个中文关键词。
3. 如果用户没有指定数量，使用 `--limit 20`。
4. 如果用户没有指定下载目录，让脚本使用默认桌面目录。
5. 检查 Python 是否可用，然后调用脚本搜索并下载。
6. 返回下载路径、匹配名称，必要时补一句简短使用建议。

## Python 环境

脚本需要 Python 3。调用前优先使用：

```bash
python --version
```

如果 `python` 不可用，再尝试：

```bash
python3 --version
```

如果两个命令都不可用，不要继续调用脚本。告诉用户需要安装 Python 3，并询问是否要帮忙安装。

安装建议：

- Windows：优先建议从 Microsoft Store 或 python.org 安装 Python 3；如果系统有 `winget`，可在用户同意后使用 `winget install Python.Python.3`。
- macOS：优先建议从 python.org 安装 Python 3；如果系统有 Homebrew，可在用户同意后使用 `brew install python`。
- Linux：根据发行版提示用户使用包管理器安装，例如 `sudo apt install python3`、`sudo dnf install python3` 或 `sudo pacman -S python`。

代为安装前必须先获得用户明确同意。安装完成后重新运行版本检查。

## 关键词提取

把用户的自然语言转换成更适合检索的表情包关键词：

- 不想上班、上班好累、今天想摆烂：`摸鱼`、`上班`、`累`、`摆烂`
- 回老板但不想答应：`收到`、`办不到`、`好的呢`、`职业假笑`
- 委婉拒绝需求：`不行`、`拒绝`、`办不到`
- 催同事进度：`进度`、`快点`、`安排`
- 开会很无聊：`开会`、`睡觉`、`发呆`
- 下班跑路：`下班`、`溜了`、`跑路`
- 被迫背锅：`背锅`、`委屈`、`无语`
- 阴阳怪气一下：`呵呵`、`你说得对`、`厉害`
- 程序员场景：`程序员`、`bug`、`需求`、`token`
- 想表达震惊或看不懂：`震惊`、`懵`、`看傻`
- 想表达敷衍但礼貌：`好的`、`收到`、`笑笑`
- 想斗图怼人：`退下`、`辣鸡`、`爬`

如果用户直接给了明确关键词，优先使用用户原词。多个关键词使用 AND 匹配，因此不要一次塞太多词；不确定时先用 1 个核心词。

## 命令

```bash
python scripts/bqb_search_download.py "摸鱼" --limit 10 --no-download
```

```bash
python scripts/bqb_search_download.py "摸鱼" --limit 10
```

如果当前系统只有 `python3`，把命令中的 `python` 替换为 `python3`。

常用参数：

- `--limit N`：最多返回或下载 N 个结果。
- `--out DIR`：指定下载目录；不指定时默认使用桌面下的 `bqb-downloads`。
- `--no-download`：只搜索，不下载。
- `--json-cache PATH`：指定本地缓存文件。
- `--refresh-cache`：强制刷新缓存。
- `--filename-only`：只按文件名匹配；一般不需要。

## 输出要求

- 优先告诉用户下载到了哪里。
- 列出 3-5 个最相关文件即可，除非用户要求完整列表。
- 如果没有结果，换更短、更口语的关键词重试一次。
- 如果用户只想挑选，不要下载，先用 `--no-download` 返回候选。
